## GameZone Pro

## Descripción

GameZone Pro es una aplicación desarrollada en Java con interfaz gráfica Swing que permite la gestión de usuarios, álbum de cartas coleccionables, tienda virtual, torneos y sistema de logros.  
El sistema implementa estructuras de datos personalizadas como listas enlazadas, colas y una malla ortogonal para la organización del álbum y la tienda.

El proyecto está orientado a la práctica de programación orientada a objetos, manejo de estructuras de datos y programación concurrente mediante hilos.

---

## Requisitos del sistema

- Java JDK 8 o superior
- NetBeans IDE (recomendado) o cualquier IDE compatible con Java
- Sistema operativo Windows, Linux o MacOS
